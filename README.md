# Dissertation
Developed a predictive model for the early detection of alcoholic and non-alcoholic liver diseases using machine learning techniques.

Go to the website and enter the clinical details from your blood test, or you can use the sample values mentioned in the placeholders according to the normal range. After clicking the Predict button, it may take around 1 minute to get the result because the backend is deployed on Render's free service, which may take some time to wake up.
